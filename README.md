# Rock Paper Scissors

Welcome to my interactive Rock Paper Scissors game, created as part of The Odin Project! This is my first ever JavaScript project, and I'm excited to share it with you.

## Features

- **Interactive Gameplay:** Play the classic game of Rock Paper Scissors against a computer opponent.
- **User-Friendly Interface:** Enjoy a simple and intuitive interface with playful emojis.
- **Responsive Design:** The game is designed to work seamlessly on different screen sizes.

## Technologies Used

- **JavaScript (38.5%):** Handles the game logic and user interactions.
- **HTML (36.8%):** Provides the structure of the game interface.
- **CSS (24.7%):** Styles the game, making it visually appealing and responsive.

## Resources

- Emojis by [Emojipedia- Microsoft Teams](https://emojipedia.org/microsoft-teams/1.0/)

## How to Play

1. Open the game in your web browser.
2. Choose Rock, Paper, or Scissors by clicking the corresponding button.
3. The computer will randomly select its choice.
4. The game will display the result - did you win, lose, or tie?
